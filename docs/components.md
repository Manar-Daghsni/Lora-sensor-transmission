# 🛠️ Components

This project uses the following hardware and software components:

## Hardware
- Arduino Uno (Transmitter & Receiver)  
- LoRa SX1276 / 868 MHz modules (one for Tx, one for Rx)  
- Potentiometer (analog sensor input)  
- Breadboard and jumper wires  
- USB cables for Arduino programming and power supply

## Software
- Arduino IDE for coding and uploading sketches  
- LoRa Arduino library (`LoRa.h`)  
- C/C++ programming  
- Serial Monitor for observing sensor values
