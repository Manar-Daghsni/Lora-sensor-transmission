# 🚀 Features

This LoRa sensor transmission project includes:

- Wireless transmission of analog sensor data using LoRa (868 MHz)  
- Real-time monitoring on the receiver Arduino via Serial Monitor  
- Low-power and long-range communication suitable for remote sensors  
- Easy integration with potentiometer  
- Adjustable update rate (currently 50 ms) for faster or slower data transmission  
- Supports basic signal quality monitoring via RSSI at the receiver  
- Simple Arduino-based setup for quick prototyping
